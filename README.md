# HiveOS — archived

This repository is the Paperclip-fork engine image of the first generation of AgentHive (May–June 2026). It is kept read-only for history and is not deployed anywhere.

The current codebase is **https://github.com/agent-hive0/agenthive**. What this generation was and why it was retired is written up in `docs/legacy.md` there.

Do not reuse code, keys or infrastructure names from this repository.
